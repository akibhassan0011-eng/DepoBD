# DepoBD - Automated Print Data Collector

A lightweight  UserScript integration designed to capture and send print repository data directly to Google Apps Script.

## 📌 Features
* **Auto Trigger:** Captures relevant print IDs before the browser print dialog fires.
* **Duplicate Prevention:** Utilizes `localStorage` tracking to prevent duplicate network payloads.
* **Data Parsing:** Automatically scrapes barcode text, agent names, and WFEXP IDs.

## ⚠️ Warning
> **DO NOT EDIT OR MODIFY THE CODE.**
> Any unauthorized modification to `Surl.js` or the metadata headers will break the execution flow and prevent data sync with the target servers.
